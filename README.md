# White Wing job tracker

Lead, order, invoice and task tracker that Reliable Office Services built for White Wing Inc.
Live at https://white-wing-tracker.vercel.app. Project details for developers (and Claude Code) are in `CLAUDE.md`.

```
npm install
npm test          # smoke test
npm run dev       # local server (needs `vercel link` + `vercel env pull .env.local`)
npm run deploy    # production deploy via Vercel CLI
```
